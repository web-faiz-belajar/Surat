# Web Nembak Cewe ♡

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser untuk mencoba.
3. Untuk GitHub Pages, upload `index.html`, `style.css`, dan `script.js` ke repository.
4. Aktifkan GitHub Pages dari Settings → Pages.

## Personalisasi
Buka `script.js`, lalu ubah bagian `CONFIG`:
- `namaPengirim`: nama kamu.
- `namaPenerima`: nama dia.
- `pin`: PIN 4 angka (default 2026).
- `petunjukPin`: petunjuk PIN.
- `pertanyaan`: pertanyaan di halaman terakhir.

Kamu juga bisa mengubah isi surat di array `letterPages` pada file `script.js`.

Catatan: PIN di web statis hanya gerbang sederhana di sisi browser, bukan sistem keamanan sungguhan.
